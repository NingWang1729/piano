# PIANO documentation

[PIANO](https://github.com/NingWang1729/piano) (Probabilistic Inference Autoencoder Networks for multi-Omics) is an integration method and a generative model for single-cell and spatial transcriptomics.

The `Composer` class is the main entry point: it selects features, trains the Etude VAE, and returns an integrated latent space plus optional counterfactual (batch-corrected) counts.
